## 📋 关于我们

**Chaeco** 是一个致力于开发**高质量开源工具**的技术社区。

我们专注于为开发者提供实用、可靠的解决方案，通过开源的方式推动技术创新与知识共享。

### 💡 核心理念

- **🎯 专注品质** - 追求代码质量和用户体验
- **🚀 解决问题** - 提供实用的开发工具和解决方案
- **🌍 开源共享** - 拥抱开源文化，与社区共同成长
- **📚 持续学习** - 探索新技术，分享最佳实践

## 🚀 技术方向

我们主要关注以下技术领域：

### 🛣️ 路由与框架工具

开发简化应用开发流程的路由管理和自动化工具，提升开发效率。

**代表项目**:
- **[route-wizard](https://github.com/chaeco/route-wizard)** - 基于文件系统的自动路由注册工具，专为 Node.js 框架设计

### 💻 技术栈

- **主要语言**: TypeScript, JavaScript
- **开发方向**: Web 开发工具、开发者效率工具
- **开源协议**: MIT License

## 🤝 如何参与

我们欢迎所有形式的贡献和参与！

### 参与方式

| 🌟 Star 项目 | 🐛 反馈问题 | 🔧 贡献代码 | 💬 交流讨论 |
|:---:|:---:|:---:|:---:|
| 给感兴趣的项目加星 | 提交 Issue 报告问题 | 提交 PR 改进项目 | 在 Discussions 分享想法 |

### 贡献步骤

1. **浏览项目** - 访问 [chaeco repositories](https://github.com/orgs/chaeco/repositories) 查看所有项目
2. **Fork & Clone** - Fork 感兴趣的项目到你的账户
3. **开发改进** - 创建分支进行开发
4. **提交 PR** - 提交 Pull Request 并描述你的改进
5. **代码审查** - 参与讨论，完善代码
