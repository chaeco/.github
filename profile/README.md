# 欢迎来到 Chaeco 👋

Chaeco 是一个专注于开源软件开发的社区，主要使用 **TypeScript** 构建高质量、可靠的工具和库。

## 🎯 我们的使命

- 🚀 开发高质量的开源软件
- 💡 为开发者提供实用的工具和库
- 🌍 支持全球开发者社区
- 📚 分享知识与最佳实践

## 🤝 如何参与

我们热烈欢迎社区贡献！

🐛 **提交 Issue** - 报告 bug 或建议新功能  
🔧 **提交 Pull Request** - 贡献代码改进  
💬 **参与讨论** - 在各项目讨论区分享想法  

详见各项目的 `CONTRIBUTING.md` 了解具体贡献步骤。

---

## 📄 许可证

我们的项目主要采用 **MIT** 许可证，具体请查看各项目的许可证文件。
